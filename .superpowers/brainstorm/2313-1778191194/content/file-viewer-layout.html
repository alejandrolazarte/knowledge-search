¿Cómo abre el File Viewer?

Tres opciones para mostrar el archivo completo desde un resultado de búsqueda

A — Panel lateral derecho

Se abre deslizando desde la derecha, igual que el panel de Skills. Los resultados quedan visibles a la izquierda. Podés navegar entre archivos sin cerrar.

B — Modal overlay

Ocupa el centro de la pantalla sobre los resultados. Bueno para leer un solo archivo. Los resultados quedan ocultos detrás.

C — Split view

La pantalla se divide: resultados a la izquierda (más angostos), archivo a la derecha. Todo visible al mismo tiempo pero más apretado.
